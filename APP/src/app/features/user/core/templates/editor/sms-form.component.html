DLT registration metadata

India's TRAI mandate requires every SMS template to be registered with a DLT portal (Jio / Airtel / VI). Submit your template via the portal first, then paste the approved IDs below — the future SMS-provider adapter uses them at send time.

Note: SMS send transport (Gupshup / MSG91 / Kaleyra) is not yet wired. Saving this template captures the metadata; the campaign dispatcher will block the send with a "configure an SMS provider in Settings → Integrations" message until the provider track lands.
