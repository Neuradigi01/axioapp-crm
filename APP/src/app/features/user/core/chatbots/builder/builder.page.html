How the bot builder works

A quick guide to designing a flow.

1. The Trigger

The green card on the left is where every conversation begins. Click it to set channel (WhatsApp / Email / any), match mode (keyword / regex / any inbound), and optionally "First message only" so the bot won't re-fire on returning customers.

2. Add nodes

Pick from the left palette (Messages tab for sends, Actions tab for asks + CRM actions). Click a tile to drop it on the canvas. The first node auto-wires from the Trigger.

3. Connect nodes

Click the small dot on the RIGHT of a node (output port) → then click the target node (or its LEFT dot). Text Button and Media Button have one dot per button row — wire each to a different downstream. Ask Question has three ports: answered / invalid / timeout.

4. Badges to watch

  • Fix — a required field is empty. Save will fail until you fill it in.
  • Orphan — the node isn't reachable from the Trigger. It will never fire.

5. Right-click a node

Opens a menu with Duplicate (copy the node + config in one click) and Delete (with confirmation).

6. Finish with End Bot

Drop an End Bot node as the last step of each branch. Optionally send a final message and mute the bot for N hours so it doesn't re-trigger on the next "hi".

7. Save & Publish

Save often (top-right button; a green toast confirms). Click Publish when you're ready — the bot only replies to real customers when it's LIVE.
