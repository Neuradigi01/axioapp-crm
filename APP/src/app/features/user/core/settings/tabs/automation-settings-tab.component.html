Quiet hours

Marketing automations don't send to customers in the window below. Runs that land inside it are deferred to the end of the window — they aren't dropped. Transactional templates (receipts, OTPs, shipment notifications) always send, even during quiet hours.

Set start and end to the same value to disable quiet hours.

Frequency cap

The maximum number of marketing messages a single contact will receive in any rolling 7-day window. Going over this cap blocks the send and records it as skipped with reason frequency_cap_exceeded. Transactional templates are not counted toward the cap.

Set to 0 to block all marketing sends regardless of consent.

DPDP marketing consent

Per the DPDP Act, marketing messages can only go to contacts who have opted in. The send-guard automatically skips any contact whose consent state is opted_out (WhatsApp) or whose email_opt_out flag is true, regardless of the cap or quiet-hours settings above. This policy is enforced — there's no toggle to disable it.
