# Step 1.3 — Database connection & Alembic

**Goal:** Wire up async SQLAlchemy engine, AsyncSession dependency, Alembic with async template, the first migration creating `organizations`, and a seed script that inserts one demo org.
**Phase:** 1
**Depends on:** 1.2
**Status:** COMPLETED

## Scope
**In-scope:**
- `api/app/shared/db.py`: async engine via `create_async_engine(settings.DATABASE_URL)`, `async_sessionmaker`, FastAPI dependency `get_session()`.
- Base declarative class with `Mapped` typed columns (SQLAlchemy 2.x style) at `api/app/shared/db.py` or `shared/orm.py`.
- `api/alembic/` initialized with async template (`alembic init -t async alembic`), `env.py` reading from `Settings`.
- `api/app/core/tenants/models.py`: `Organization` model with `id` (UUID), `name`, `slug`, `pack_id`, `pack_version`, `currency`, `tax_rate`, `timezone`, `created_at`.
- First migration `0001_organizations.py` (autogenerated, then hand-checked).
- `api/app/scripts/seed_demo_org.py`: inserts the demo organization (idempotent — `INSERT ... ON CONFLICT DO NOTHING`).
- Output the demo-org INSERT SQL to the user (per CLAUDE.md rule for seed routes).

**Out of scope:**
- Users/roles tables — 1.5.
- RLS policies — 1.4.
- Auth — 1.6.

## Plan
1. Implement `shared/db.py` with `engine`, `AsyncSessionLocal`, `Base`, `get_session()` dependency.
2. Define `Organization` (UUID PK via `gen_random_uuid()`, `slug` unique, `pack_id='furniture'` default, `tax_rate` Numeric(5,2) default 18.00, `currency` default 'INR', `timezone` default 'Asia/Kolkata').
3. `cd api && uv run alembic init -t async alembic` then customize `env.py` to import `Base` and `Settings`, set `target_metadata = Base.metadata`.
4. `uv run alembic revision --autogenerate -m "create organizations"` — review the generated SQL, ensure UUID + timestamp defaults and `pgcrypto` extension call.
5. `uv run alembic upgrade head` — confirm clean run.
6. `uv run alembic downgrade base` — confirm clean rollback. Re-upgrade.
7. Implement `seed_demo_org.py` as an async script: opens session, upserts demo org with fixed UUID, commits, prints the row.
8. Print raw INSERT SQL block at end of step report so the user can run it directly.
