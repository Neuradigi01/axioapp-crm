Build Plan

Seven steps to ship Campaigns v1 · WhatsApp + Email

Steps

#StepTrackScreens affectedEffort
01WA approval + category + language badges in campaign template pickerWhatsAppNew Campaign wizardSmall
02WA rejection reason tooltip on library + picker badgesWhatsAppWA Templates list · New Campaign wizardSmall
03Email sender identity + reply-to + subject + preheader on templateEmailCreate Email Template · Sender SetupMedium
04HTML composer + rich preview + merge tag inserterEmailCreate Email TemplateMedium
05Wire dispatch to adapter.send_email() — funnel + trackingEmailCampaign ReportMedium
06Auto-append unsubscribe footer + email_opt_in_status on ContactEmailCreate Email Template · Wizard exclusionsMedium
07Email Sender Setup page (domain + address verification, SPF/DKIM/DMARC) + bounce suppression in wizardEmailSender Setup · Wizard exclusionsLarge

Ship gates

  • After Step 02 — WhatsApp v1 UX complete. Users see approval status inline, understand rejection reasons without leaving CRM.
  • After Step 05 — Email happy path works. Templates → send → funnel visible.
  • After Step 07 — Campaigns v1 ready for real customers. Sender verification, compliance footer, bounce suppression all in place.
Out of scope for v1: SMS · Voice · Messenger · Instagram · Web · Push · multi-channel fallback chains · journey campaigns · wallet debit / cost estimator · plan gating · channel readiness dashboard
