FurniCRM widget — dev host

Local-only page that loads the widget bundle exactly like a customer site would. Pass ?key=pk_live_… in the URL to test against a real key issued from Settings → Embed Widget.

Default key is pk_live_devplaceholder which won't validate against the backend — the widget will render an error. Issue a real key from /user/settings → Embed Widget → Issue new key and append ?key=… to this URL to test the full flow.
